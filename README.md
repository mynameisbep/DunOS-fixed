# DunOS (aka DunDunDunPlaysOS)

Welcome to **DunOS**! This is the official operating system project by the DunDunDunPlays Productions team. 

## 🚀 Current Status: Early Access
DunOS is currently written in **Java** and is in its early access phase. 

* **The Backstory:** We originally attempted to build this project using HTML, but it didn't quite hit the mark. We pivoted to Java to give the system a much stronger, more capable foundation.

## 🤝 We Love Open Source!
DunOS is proudly **open source**. We believe in community-driven development and love the open-source philosophy. Feel free to explore the code, experiment, and contribute!

## 🐛 Reporting Issues
Notice a bug? Have a feature request? Please let us know! 
* Head over to the **Issues** tab right here on GitHub to file a report. 
* Your feedback directly helps us make DunOS better with every update.
