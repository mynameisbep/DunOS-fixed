## DunOS (aka DunDunDunPlaysOS)

Welcome to **DunOS**! This is the official operating system project by the DunDunDunPlays Productions team. 

## 🚀 Current Status: Early Access
DunOS is currently written in **Java** and is in its early access phase. 

* **The Backstory:** We originally attempted to build this project using HTML, but it didn't quite hit the mark. We pivoted to Java to give the system a much stronger, more capable foundation.

## 🛠️ How to Build & Run

Make sure you have the Java Development Kit (JDK 15 or newer recommended) installed on your system. Open your terminal in the root `DunOS` directory and copy the one-liner command that matches your operating system:

```bash
# For Linux & macOS (Terminal)
javac -d out src/dunos/**/*.java && java -cp out dunos.Main

# For Windows (Command Prompt)
javac -d out src/dunos/Main.java src/dunos/core/*.java src/dunos/ui/*.java src/dunos/system/*.java src/dunos/util/*.java src/dunos/apps/*.java && java -cp out dunos.Main

# For Windows (PowerShell)
javac -d out (Get-ChildItem src/dunos/**/*.java).FullName; java -cp out dunos.Main

```
